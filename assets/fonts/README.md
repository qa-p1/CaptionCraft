# Caption fonts

These font files are bundled so Flutter preview and FFmpeg/libass export use the
same deterministic families on every supported device.

All files were obtained from the official
[Google Fonts repository](https://github.com/google/fonts/tree/main/ofl):

- `Roboto-*` from `ofl/roboto`
- `Inter-*` from `ofl/inter`
- `Poppins-*` from `ofl/poppins`
- `Montserrat-*` from `ofl/montserrat`
- `PlayfairDisplay-*` from `ofl/playfairdisplay`
- `SpaceMono-*` from `ofl/spacemono`

Each family is distributed under the SIL Open Font License 1.1. The
family-specific license text is preserved in `licenses/`.
