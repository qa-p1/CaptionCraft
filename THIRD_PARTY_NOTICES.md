# Third-party notices and source status

CaptionCraft-owned code is GPL-3.0-or-later. Dependencies, fonts, system libraries
and imported media retain their own licenses/notices. The app's license screen
contains notices generated by Flutter. This inventory does not claim that all
binary-distribution requirements have already been fulfilled.

## Dependency records

- `pubspec.lock`: resolved Dart/Flutter packages and archive hashes.
- App/plugin Gradle files: Android native dependency declarations.
- The successful iOS artifact's `Podfile.lock`: actual resolved native pods.
- Windows workflow: pinned native archives/hashes; ZIP `BUILD-INFO.json`: build provenance.
- `assets/fonts/licenses/`: bundled font licenses.

Flutter/Dart, Firebase, Google Sign-In, cryptography, secure storage, media,
windowing and URL-launching packages retain their upstream notices. Preserve
Flutter-generated notices and each dependency's supplied license files.

## FFmpeg and FFmpegKit

The Flutter wrapper is `ffmpeg_kit_flutter_new` 4.6.2:
[upstream repository](https://github.com/sk3llo/ffmpeg_kit_flutter),
[published package](https://pub.dev/packages/ffmpeg_kit_flutter_new/versions/4.6.2).
It supplies LGPL v3 and GPL v3 license texts. The selected **Full-GPL** variant
must not be described as an LGPL-only binary. See
[FFmpeg licensing guidance](https://ffmpeg.org/legal.html).

| Platform | Native input |
| --- | --- |
| Android | Maven `com.antonkarpenko:ffmpeg-kit-full-gpl:2.2.1` |
| iOS | `ffmpeg-kit-ios-full-gpl-8.1.2.zip` |
| Windows | `ffmpeg-kit-windows-x86_64-full-gpl-8.1.2.zip` |

The iOS/Windows inputs come from
[`8.1.2-full-gpl`](https://github.com/sk3llo/ffmpeg_kit_flutter/releases/tag/8.1.2-full-gpl),
tag commit `437356ab7efb22ba0a70cbf23ca4bf7b3f693d38`. The Windows archive's pinned
SHA-256 is `83d67fec21e569c8e8177b3c7ac7d7579785582672b6ee3cab72fbec320b4215`.
It also bundles separately licensed x264/x265, libass, font, compression and
other support libraries. A Flutter-wrapper source tag does not supply all of
those native sources.

### Source-provenance prerequisite

Before public binary distribution, obtain/verify the exact FFmpeg/FFmpegKit
sources, patches, dependency revisions and native build recipes for each input.
Provide the required corresponding source alongside the binaries and retain
their notices. An arbitrary FFmpeg snapshot or binary-download link is not a
verified corresponding-source package.

The maintainer links
[`sk3llo/ffmpeg_kit_flutter_android`](https://github.com/sk3llo/ffmpeg_kit_flutter_android)
in [source-code issue #104](https://github.com/sk3llo/ffmpeg_kit_flutter/issues/104).
The inspected repository contains wrapper/packaging code and a script downloading
a prebuilt AAR. A complete source/build mapping for Maven 2.2.1 was not established.
No complete corresponding-source package was verified for the iOS/Windows 8.1.2
inputs either. This is recorded rather than inventing a source offer we cannot fulfill.

The Maven 2.2.1 `-sources.jar` was also inspected: it contains 32 Java source
files, but no native C/C++ sources, patches or native build scripts. Its POM
describes FFmpeg 8.1.1 and points to an unavailable hyphenated GitHub repository.
The Java source JAR alone does not resolve the native-source prerequisite.
